# Credits

## Texturen

Alle Bodentexturen stammen von [ambientCG](https://ambientcg.com) und stehen unter **CC0 1.0** (gemeinfrei). Für das Spiel wurden sie neu als JPG kodiert; Rauheit und Umgebungsverdeckung sind auf 512 px verkleinert.

| Datei im Spiel | Original | Verwendung |
|---|---|---|
| `game/assets/terrain/dirt_*` | [Ground102](https://ambientcg.com/view?id=Ground102) | trockener, verdichteter Boden |
| `game/assets/terrain/gravel_*` | [Ground110](https://ambientcg.com/view?id=Ground110) | Geröll, Hangfüße, Fahrspuren |
| `game/assets/terrain/rock_*` | [Rock061](https://ambientcg.com/view?id=Rock061) | Felsflanken der Berge |
| `game/assets/terrain/grass_*` | [Ground037](https://ambientcg.com/view?id=Ground037) | Moos und Gras in den Senken |

Lizenz: https://creativecommons.org/publicdomain/zero/1.0/

## Schrift

Alle Texte im Spiel nutzen **Fira Mono Regular** von Mozilla und Telefónica ([github.com/mozilla/Fira](https://github.com/mozilla/Fira)), unverändert als `game/fonts/FiraMono-Regular.ttf`. Lizenz: **SIL Open Font License 1.1**, der vollständige Text liegt in `game/fonts/FiraMono-OFL.txt`.

Fahrzeuge, Gebäude, Vegetation, Gelände-Relief, Effekte und Shader sind im Code dieses Projekts erzeugt.
